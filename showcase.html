WORKBUDDY SKILL

一周选题生成器

上传历史爆款，AI 拆出你的爆款规律，批量产出下周选题
3-5 篇历史爆款→ 拆结构→ 抽规律→ 15-20 个选题
制作人 kk2056 · 抖音 / 小红书双平台

Why

选题枯竭，不是没灵感

真正的根因是：你从没把自己账号的爆款规律拆出来过。所以每次都从零开始想， 想出来的还没上次的好使。

这个 skill 干一件事：从你自己的历史爆款里抽规律，再按规律量产选题。 每条选题都挂着一条你数据里的规律，不是通用模板硬套。

What you get

跑一次，拿到三样东西

01
逐篇拆解表
选题角度 / 开头钩子 / 行文结构 / 标题特征，四个维度拆明白你过去的爆款到底赢在哪
02
三条共性规律
你账号专属的爆款模式——开头怎么钩、标题怎么起、结构怎么铺。不是通用鸡汤
03
15-20 个选题
抖音 / 小红书分开设计，每条带选题角度、建议标题、开头钩子、内容形式、推荐等级

How

四步走完

1
准备 3-5 篇历史爆款
markdown / txt / docx 都行。每篇至少要有标题 + 开头 3 秒 + 整体结构，只有标题不够
2
新建会话，上传素材
在 WorkBuddy 里开一个新会话，把内容丢进去
3
说清定位和平台
告诉 AI 你的账号定位是谁、目标平台是抖音、小红书，还是都要
4
拿结果
拆解表 → 共性规律 → 选题清单，一次拿全
硬门槛：不足 3 篇，AI 会停下来让你补素材，绝不硬凑。

Rules

四条不破的底线

不编造 数据或案例。素材里没有的，不瞎补
不输出 与爆款规律无关的选题
不输出 纯品牌宣传 / 硬广选题
不足 3 篇 不硬生成，先提醒补素材

Install

装好就能用

丢进 ~/.workbuddy/skills/one-week-topic-generator/
然后直接说「帮我找选题」「一周选题」「没选题了」，自动触发。
