# 输入示例：3 篇历史爆款内容

> 这是「一周选题生成器」的输入样例。实际使用时，把你自己账号的 3-5 篇历史爆款贴进来即可。
> 每篇至少要有：**标题、开头 3 秒、整体结构**。只有标题不够，AI 拆不出规律。

账号定位：AI 工具 / AI 提示词博主，面向想用 AI 省时间但不知从哪下手的普通上班族。

---

## 爆款 1（抖音 · 口播）

- **标题**：一个人加一个 AI，干完新媒体运营那堆活
- **数据**：播放 153.6w / 赞 4.2w
- **开头 3 秒**：「我一个人，加一个 AI，把原来三个人的活干完了。」
- **结构**：
  1. 结果前置：直接甩出"一个人干完三个人的活"
  2. 拆三个环节：选题 → 写稿 → 剪片
  3. 每个环节给具体工具名 + 一句提示词
  4. 结尾甩结果对比：原来 8 小时，现在 2 小时
- **结尾动作**：引导评论"想要提示词的扣 1"

---

## 爆款 2（小红书 · 图文）

- **标题**：做新媒体最累的从来不是拍视频
- **数据**：赞 2.3w / 收藏 1.8w
- **开头首句**：「做新媒体最累的从来不是拍视频，是每天睁眼就想今天拍什么。」
- **结构**：
  1. 痛点戳穿：先否定一个大家默认的答案
  2. 列 3 个"真正累"的点：选题、改稿、复盘
  3. 每个点给一个可立刻上手的解法
  4. 结尾引导收藏："建议收藏，选题枯竭的时候翻出来"
- **结尾动作**：引导收藏

---

## 爆款 3（抖音 · 口播）

- **标题**：这个 AI 提示词你没用过是吧
- **数据**：播放 25.2w / 赞 9800
- **开头 3 秒**：「这个提示词你没用过是吧？没用过就对了，用过的人都已经不自己写了。」
- **结构**：
  1. 挑衅式钩子：先用一句"你没用过是吧"制造缺口
  2. 现场演示：同一件事，普通问法 vs 这个提示词，结果直接对比
  3. 讲清楚差在哪一句话
  4. 结尾把提示词原文甩出来
- **结尾动作**：引导截图保存

---

## 这 3 篇能被拆出什么

| 篇 | 开头钩子类型 | 结构 |
|----|------------|------|
| 1 | 数字结果前置 | 结果 → 拆步骤 |
| 2 | 痛点 + 否定常识 | 戳痛点 → 列清单 → 给解法 |
| 3 | 挑衅式反常识 | 演示对比 → 甩原文 |

**共同点**：三篇全都是「先给结果或先戳痛点，再讲怎么做」，没有一篇是先铺垫背景、先讲原理的。
