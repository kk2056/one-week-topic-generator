## 30 秒看懂

选题枯竭的根因，不是没灵感，是**你从没把自己账号的爆款规律拆出来过**。

这个 skill 干一件事：

```
你的 3-5 篇历史爆款  →  拆结构  →  抽规律  →  按规律量产下周选题
```

产出的每一个选题，都能追溯到你自己数据里的一条规律。不是通用模板硬套，不是"也许可以试试"。

---

## 你会拿到什么

跑一次，拿到三样东西：

**① 逐篇拆解表** — 你过去的爆款到底赢在哪

| 篇 | 选题角度 | 开头钩子 | 行文结构 | 标题特征 |
|---|---|---|---|---|
| 《一个人加一个AI》 | 解决"一个人干不完运营全流程" | 数字结果前置 | 结果 → 拆3环节 | 强反差、有人物对比 |
| 《最累的不是拍视频》 | 解决"每天选题枯竭" | 痛点+否定常识 | 戳痛点 → 列清单 | 否定句式制造悬念 |
| 《这个提示词你没用过是吧》 | 解决"提示词写了没效果" | 挑衅式反常识 | 演示对比 → 甩原文 | 第二人称、带挑衅感 |

**② 三条共性规律** — 你账号专属，不是通用鸡汤

> 示例：开头 3 秒必给结果或戳痛点，从不铺垫背景 · 标题二选一（具体数字 or 强反差）· 每条都留一个能立刻抄走的动作

**③ 15-20 个选题清单** — 抖音 + 小红书分开，可直接开拍

| 平台 | 选题角度 | 建议标题 | 开头钩子 | 内容形式 | 是否推荐 |
|---|---|---|---|---|---|
| 抖音 | 解决"提示词写了没用" | 你写的提示词没用，是因为少了这一句 | 反常识 | 口播+演示 | ✅ |
| 抖音 | 解决"AI文案一眼假" | AI写的文案一眼假，问题出在开头这3句 | 痛点 | 口播+对比 | ✅ |
| 小红书 | 解决"AI味太重" | 一眼AI写的文案，都有这3个毛病 | 痛点 | 图文清单 | ✅ |
| 小红书 | 解决"提示词存不住" | 我把常用的AI提示词整理成了这一张表 | 利益点 | 图文+表格 | ✅ |

> 完整 18 条见 `examples/output_example.md`

## 有它 vs 没它

| | 没这个 skill | 有这个 skill |
|---|---|---|
| 选题从哪来 | 刷同行、抄爆款、等灵感 | 从你自己账号的数据规律推 |
| 一周能出几个 | 蹲半天憋 3 个 | 一次 15-20 个 |
| 为什么能爆 | 说不清，靠感觉 | 每条都挂着一条你的爆款规律 |
| 平台差异 | 一个选题两头硬发 | 抖音 / 小红书分开设计 |
| 废选题 | 混在里面，拍完才发现 | 硬广、脱定位的，生成时就剔除 |

## 怎么用

**第 1 步** — 准备 **3-5 篇**你的历史爆款（markdown / txt / docx 都行）

每篇至少要有三样：**标题 + 开头 3 秒 + 整体结构**。只有标题不够，拆不出规律。

**第 2 步** — 新建会话，上传素材

**第 3 步** — 告诉 AI 两件事：你的**账号定位**、**目标平台**

**第 4 步** — 拿结果：拆解表 → 共性规律 → 选题清单

> 🔴 **不足 3 篇，AI 会停下来让你补素材，绝不硬凑。**

---

## 它会拆什么

每一篇爆款，拆四个维度：

| 维度 | 拆的是什么 |
|---|---|
| **选题角度** | 解决了**谁**的**什么问题** |
| **开头钩子** | 前 3 秒用了什么手法（数字 / 结果 / 痛点 / 反常识 / 挑衅） |
| **行文结构** | 整体框架（问题-方案-案例 / 清单 / 故事线 / 演示对比） |
| **标题特征** | 关键词、句式、有没有数字 / 悬念 / 利益点 |

---

## 硬规则

生成完会先自己筛一遍再给你：

| 过滤项 | 处理 |
|---|---|
| 纯广告 / 硬广 / 品牌宣传 | 🔴 直接剔除 |
| 与账号定位不符 | 🔴 直接剔除 |
| 跟爆款规律无关 | 🔴 直接剔除 |
| 方向对但把握一般 | 保留，标 ⚠️ 往后排 |

还有四条不破的底线：

- **不编造数据或案例** — 素材里没有的，不瞎补
- **不输出与规律无关的选题** — 每条都要能追到一条规律
- **不输出纯品牌宣传**
- **不足 3 篇不硬生成**

## 安装

```bash
# 放到 WorkBuddy 的 skills 目录
~/.workbuddy/skills/one-week-topic-generator/
```

装好后直接说「**帮我找选题**」「**一周选题**」「**没选题了**」，自动触发。

## 适合谁

- 有 **3 篇以上**历史爆款，但说不清它们为什么爆
- 每周为选题发愁，想一次性把下周的排满
- 抖音 / 小红书**双平台**运营，需要分开设计选题
- 不想再靠"刷同行找感觉"
