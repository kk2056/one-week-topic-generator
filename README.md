# one-week-topic-generator · 一周选题生成器

> 制作人：kk2056

上传历史爆款内容，AI 自动拆结构、找规律，每周批量生成适合你赛道的 15-20 个选题。

---

## 它解决什么问题

选题枯竭的根因不是"没灵感"，是**你没把自己账号的爆款规律拆出来**。

这个 skill 干的事：从你自己的历史爆款里抽规律 → 按规律批量产出下一周的选题。产出的每一个选题都能追溯到一条你自己的数据规律，不是通用模板硬套。

## 功能

- 拆解历史爆款的**选题角度 / 开头钩子 / 行文结构 / 标题特征**
- 归纳你账号专属的**三条共性规律**
- 批量生成 **15-20 个**抖音 + 小红书选题
- 自动剔除硬广、品牌宣传、脱离账号定位的选题

## 使用方法

1. 在 WorkBuddy 里新建会话
2. 上传 **3-5 篇**你的历史爆款内容（markdown / txt / docx 都行）
   - 每篇至少要有**标题 + 开头 3 秒 + 整体结构**，只有标题不够
3. 调用本 skill，告诉 AI 你的**账号定位**和**目标平台**
4. 拿到：拆解表 → 共性规律 → 选题清单

🔴 **不足 3 篇，AI 会停下来让你补素材，不会硬凑。**

## 输出格式

| 平台 | 选题角度 | 建议标题 | 开头钩子 | 内容形式 | 是否推荐 |
|---|---|---|---|---|---|

是否推荐：**✅ 推荐** / **⚠️ 可选** / ❌（已剔除，不出现在表里）

## 硬规则

- 不编造数据或案例
- 不输出与爆款规律无关的选题
- 不输出纯品牌宣传类选题
- 不足 3 篇素材，先提醒补充

## 文件结构

```
├── prompt.md                   # 核心 prompt（Role / Task / Output Format / Rules）

    ├── input_example.md        # 输入示例：3 篇历史爆款
    └── output_example.md       # 输出示例：拆解 + 规律 + 18 个选题
```

## 安装

放到 WorkBuddy 的 skills 目录下：

```
~/.workbuddy/skills/one-week-topic-generator/
```

然后直接说"帮我找选题"或"一周选题"，skill 会自动触发。
